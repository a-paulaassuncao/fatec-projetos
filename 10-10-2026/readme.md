# O que é o sistema de cores CMYK?

O CMYK é um sistema de cores baseado em pigmentos, usado principalmente na produção de materiais impressos.

A sigla representa quatro cores primárias:

- **C** – Cyan (Ciano)
- **M** – Magenta (Magenta)
- **Y** – Yellow (Amarelo)
- **K** – Key (Preto, usado como chave de profundidade e contraste)
